# 모루 — 나만의 홈트레이닝 PWA

> **모루** = Move + Routine. 대장간에서 쇠를 두드려 단련하는 받침대 '모루'처럼, 매일 조금씩 몸을 단련해요.

**👉 앱 바로 열기: https://yumin365.github.io/moru/**

휴대폰·태블릿에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요 (크롬: ⋮ → 홈 화면에 추가 / 사파리: 공유 → 홈 화면에 추가).

앱을 열고 **운동 시작** 버튼만 누르면, 오늘 날짜의 영상이 순서대로 재생돼요.

```
스트레칭 1 → 운동 1 → 운동 2 → 스트레칭 2 → 완료
```

- 서버·로그인·유료 API 없음. 기록은 이 기기의 `localStorage`에만 저장돼요.
- GitHub Pages로 무료 배포. 홈 화면에 추가하면 앱처럼 실행돼요 (PWA, 오프라인에서도 앱 화면과 기록은 열려요).
- 영상은 YouTube 공식 임베드 플레이어로 재생해요. 다운로드나 캐싱은 하지 않아요.

---

## 1. 실행 방법

Node.js 20.19 이상(또는 22.12 이상)이 필요해요.

```bash
npm install
```

```bash
npm run dev
```

브라우저에서 `http://localhost:5173` 을 열면 돼요. 같은 Wi-Fi의 갤럭시탭에서는 터미널에 표시되는 `Network:` 주소로 접속하세요.

| 명령 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 |
| `npm run build` | 타입 검사 + 배포용 빌드 (`dist/`) |
| `npm run preview` | 빌드 결과 미리보기 (서비스 워커 포함) |
| `npm test` | 날짜·streak·URL 파싱 등 로직 테스트 |

> **다른 날짜로 테스트하기:** 주소 끝에 `?date=2026-10-20` 을 붙이면 그날을 "오늘"로 보여줘요.

## 2. 운동 일정 수정 위치

**`src/data/workoutSchedule.ts`** — 날짜별로 운동 1·2를 적는 파일이에요.

```ts
'2026-10-13': {
  workout1: { title: '하체 불태우기', youtubeUrl: 'https://youtu.be/VIDEO_ID', durationMin: 12, category: '지니다이어트' },
  workout2: { title: '코어 운동', youtubeUrl: 'https://www.youtube.com/watch?v=VIDEO_ID', durationMin: 10 },
},
'2026-10-18': { rest: true }, // 휴식일 — 연속 기록이 끊기지 않아요
```

- 지금 들어있는 2026년 10–11월 데이터는 **더미 데이터**(공개 샘플 영상)예요.
- Claude Code에게 *"10월 운동 일정을 이 데이터로 바꿔줘"* 라고 캘린더 내용을 주면 이 파일만 고치면 돼요.
- `durationMin`(분)과 `category`(라벨)는 선택이에요. 시간을 비워두면 처음 재생할 때 자동으로 기록돼요.
- 일정 파일에 없는 날짜는 기본 스트레칭만 보여요.

## 2-1. 지니다이어트 이달의 루틴 연동

[지니다이어트 이달의 루틴](https://www.jinydiet.com/routine)은 로그인이 필요하고, 달력이 **이미지 + 영상 링크** 형태로 올라와요.
그래서 서버 없이 **내 브라우저에서 북마크 한 번**으로 가져와요 (로그인 정보는 앱이 다루지 않아요).

1. 앱 **설정 → 지니다이어트 루틴 카드의 "북마크 설정" → 북마크 코드 복사**
2. 크롬에서 아무 페이지나 북마크(☆) → **수정** → 이름 `지니가져오기`, URL에 복사한 코드 붙여넣기 (처음 한 번만)
3. 매달: 로그인한 상태로 [이달의 루틴] 페이지를 열고, 주소창에 `지니가져오기` 입력 → 북마크 항목 선택
4. 앱이 열리면서 그달 달력을 자동으로 인식해요 (날짜·영상·시작 시간). 영상 이름을 확인/수정하고 **적용하기**

- 영상 링크에 들어있는 시작 시간(`t=61` 등)도 그대로 적용돼서 지니쌤이 지정한 지점부터 재생돼요.
- 영상 이름을 달력에 적힌 짧은 이름으로 바꿔두면 다음 달에도 그대로 써요.
- 가져온 루틴은 **이 기기에만** 저장돼요 (회원 전용 콘텐츠라 GitHub 저장소에는 올리지 않아요). 우선순위: 직접 편집한 날 > 가져온 루틴 > 일정 파일.
- 북마크는 크롬에서 동작을 확인했어요. 북마크 링크는 앱 주소가 들어가 있으니, **GitHub Pages에 배포한 뒤 그 주소에서 복사**하세요.
- 사이트 구조가 바뀌어 달력을 못 찾으면 알림이 떠요. 그때는 Claude Code에 알려주세요.

## 3. YouTube 링크 넣는 방법

`youtubeUrl`에 공개 영상 주소를 그대로 붙여넣으면 돼요. 아래 형태 모두 지원해요.

```
https://www.youtube.com/watch?v=VIDEO_ID
https://youtu.be/VIDEO_ID
https://www.youtube.com/shorts/VIDEO_ID
https://www.youtube.com/embed/VIDEO_ID   (t=90 같은 시작 시간도 인식)
```

**앱 안에서 바꾸기:** 오늘 화면의 **편집** (또는 캘린더 → 날짜 선택 → **루틴 편집**)에서 영상 제목·링크 붙여넣기·순서 변경·추가·삭제가 가능해요. 링크를 붙여넣으면 영상 제목이 자동으로 채워져요. 앱에서 바꾼 내용은 그 날짜에만 적용되고, **초기화**를 누르면 일정 파일 내용으로 돌아가요.

**매주 반복:** 루틴 편집에서 영상의 **매주 반복**을 켜면 기본은 **매일 반복**이고, "특정 요일만 반복하고 싶어요"를 켜면 요일을 고를 수 있어요. 그날 이미 같은 영상이 있으면 중복으로 넣지 않아요. 설정 → **반복 루틴**에서 기본 스트레칭과 반복 영상을 한곳에서 보고, 추가·수정·멈추기를 할 수 있어요. 바꾼 내용은 그날부터 적용되고 지난 날짜 기록은 그대로예요.

**영상 길이:** `durationMin`을 비워두면 앱이 숨겨진 YouTube 플레이어로 길이를 미리 재요(무료, API 키 없음). 링크에 시작 시간(`t=130s`)이 있으면 그만큼 뺀 실제 재생 길이로 계산해요. 아직 재는 중인 영상이 있으면 총 시간 뒤에 `+`가 붙어요.

> 일부 영상은 소유자가 외부 앱 재생을 막아두었어요. 그런 영상은 플레이어에 안내가 뜨고 **YouTube에서 열기**로 볼 수 있어요.

## 4. 기본 스트레칭 영상 변경 방법

**`src/config/appConfig.ts`**

```ts
const defaultStretchVideo = { title: '아침 스트레칭', youtubeUrl: 'https://youtu.be/...', durationMin: 7 };   // 스트레칭 1
const defaultStretch2Video = { title: '마무리 스트레칭', youtubeUrl: 'https://youtu.be/...', durationMin: 10 }; // 스트레칭 2 (null이면 1과 동일)
```

- 특정 날만 다른 스트레칭: 일정 파일에서 그 날짜에 `stretch1: {...}` / `stretch2: {...}` 지정 (`null`이면 그날 스트레칭 없음).
- 앱 안에서: **설정 → 반복 루틴 → 스트레칭 항목**. 영상과 요일을 바꿀 수 있어요. (앱에서 정한 값이 파일보다 우선해요. "앱 기본값으로"를 누르면 파일 값으로 돌아가요.)
- 휴식일 스트레칭 표시, 주 시작 요일, 연속 기록 규칙도 같은 파일에 있어요.

## 5. GitHub Pages 배포 방법

1. GitHub에 새 저장소를 만들고 이 폴더를 push 해요.
   ```bash
   git init
   ```
   ```bash
   git add . && git commit -m "모루"
   ```
   ```bash
   git branch -M main && git remote add origin https://github.com/<아이디>/<저장소>.git && git push -u origin main
   ```
2. 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 선택해요.
3. `main` 에 push 할 때마다 `.github/workflows/deploy.yml` 이 테스트·빌드 후 자동 배포해요.
   주소: `https://<아이디>.github.io/<저장소>/` (이 저장소: https://yumin365.github.io/moru/)
4. 휴대폰/갤럭시탭에서 그 주소를 열고
   - Chrome: ⋮ 메뉴 → **홈 화면에 추가** (또는 앱 설치)
   - Safari: 공유 → **홈 화면에 추가**

자산 경로가 모두 상대 경로(`base: './'`)라서 저장소 이름이 무엇이든 하위 경로에서 그대로 동작해요. 라우터 없이 탭 전환만 쓰기 때문에 GitHub Pages 404 문제도 없어요.

> 새 버전을 배포하면 앱을 한 번 닫았다 다시 열면 최신 버전으로 바뀌어요.

## 6. 저장된 운동 기록 초기화 방법

- 앱에서: **설정(톱니바퀴) → 맨 아래 "초기화" 펼치기 → 운동 기록 초기화** (확인 창이 한 번 더 떠요).
  편집한 루틴과 스트레칭 설정까지 지우려면 **전체 초기화**.
- 브라우저에서 사이트 데이터를 지워도 초기화돼요.
- 기록은 이 기기에만 있어요. 기기를 바꾸거나 데이터를 지우기 전에 **설정 → 백업 내보내기**로 `.json` 파일을 저장해 두고, **백업 가져오기**로 복원하세요.

## 7. 꾸미기 · 앱 아이콘

**설정 → 화면 → 꾸미기**에서 이 기기의 앱을 꾸밀 수 있어요. 사진은 모두 이 기기(IndexedDB)에만 저장돼요.

| 탭 | 내용 |
| --- | --- |
| 테마 색 | 추천 색 조합 또는 메인·보조 색, 바탕 톤 직접 고르기 |
| 배경 | 오늘·캘린더·통계 화면별 배경 사진 (여러 화면 같이 선택 가능), 흐림·밝게 덮기·반투명 카드 |
| 스티커 | 내 사진으로 스티커 만들기, 화면에서 끌어서 위치·크기·각도 바꾸기 |
| 도장 | '참 잘했어요' 기본 도장 또는 내 이미지, 잉크 질감·색·기울기·애니메이션 켜고 끄기 |
| 아이콘 | 내 사진을 1:1로 잘라 홈 화면 앱 아이콘으로 쓰기 (기본: `mo.`) |

- 사진을 올리면 바로 쓰이지 않고 **자르기·회전·확대 편집 화면**이 먼저 떠요. 미리보기도 같이 보여요.
- 앱 아이콘은 **홈 화면에 추가할 때** 들어가요. 이미 추가했다면 지우고 다시 추가해야 바뀌어요.
- **디자인 내보내기/가져오기**(설정 → 화면)로 꾸미기만 파일로 주고받을 수 있어요. 운동 기록은 들어가지 않아요.
- 기본 아이콘 파일은 `public/icons/`에 있어요. 같은 이름·크기의 PNG로 바꾸면 기본 아이콘이 바뀌어요.

## 8. 처음 시작 안내

처음 여는 사람에게만 4단계 안내(소개 → 색과 아이콘 → 홈 화면에 추가 → 지니 연동)가 떠요. 이미 기록이 있는 기기에는 뜨지 않아요.
처음 한 번만 뜨는 팁(오늘 · 캘린더 · 플레이어)도 있어요. **설정 → 앱 → 사용법 다시 보기**로 다시 볼 수 있어요.

## 9. 할 일 · 순서 바꾸기

- 오늘 화면의 **＋ 할 일 추가**로 글자만 있는 할 일을 넣어요. 반복을 켜면 매일 / 특정 요일마다 들어가요. 새 할 일은 루틴 맨 위에 들어가요.
- 할 일도 루틴의 한 항목이에요. 진행률·캘린더 색·도장·연속 기록·통계 완료율에 영상과 똑같이 1개로 들어가요. 운동 시간은 영상만 계산해요.
- 플레이어는 영상만 재생해요. 할 일은 목록에서 체크해요.
- 어제 못 한 하루짜리 할 일은 **오늘로 옮기기** 버튼으로 옮길 수 있어요.
- 카드(영상·할 일)를 **꾹 길게 누르면** 위아래로 끌어서 순서를 바꿀 수 있어요. 바꾼 순서는 다른 날에도 적용돼요.

## 10. 파란색 기록

캘린더의 두 번째 색(기본: 근력 운동)을 원하는 습관으로 바꿀 수 있어요. **설정 → 운동 설정 → 파란색 기록**

| 기록 방법 | 동작 |
| --- | --- |
| 직접 답하기 | 오늘 화면 진행 카드의 버튼으로 켜고 꺼요. '운동 마치면 물어보기'를 켜면 완료 화면에서도 물어요 |
| 할 일로 체크 | 연결한 반복 할 일을 끝낸 날이 파란색이 돼요 |
| 사용 안 함 | 캘린더를 한 가지 색으로만 써요. 통계 칸은 '완료한 할 일'로 바뀌어요 |

---

### 기록 규칙

| 항목 | 규칙 |
| --- | --- |
| 완료 | 영상이 끝까지 재생되면 자동 완료. 플레이어의 **완료로 표시** 또는 카드의 체크로 직접 표시 |
| 완료 취소 | 오늘 카드의 체크를 다시 누르면 확인 후 취소. 지난 날은 캘린더 → **기록 수정** |
| 연속 기록 | 영상·할 일을 1개 이상 완료한 날이 이어지면 증가. 휴식일은 건너뛰고, 아직 안 한 오늘은 끊기지 않음 (설정 → 연속 기록 기준에서 "모두 완료"로 변경 가능) |
| 캘린더 색 | 테마 메인 색 = 기록한 날(영상·할 일), 보조 색 = 파란색 기록(기본: 근력 운동). 색이 진할수록 많이 완료 |

### 폴더 구조

```
src/
  config/appConfig.ts        기본 스트레칭, 라벨, 주 시작 요일, streak 규칙
  data/workoutSchedule.ts    월간 운동 일정 (더미 데이터)
  lib/                       날짜, YouTube URL 파싱, 일정 계산, 통계/streak, 저장소
  state/                     기록 저장소(localStorage), 토스트, 오늘 날짜, 뒤로가기 처리
  components/                버튼, 시트, 체크, 진행 링, 썸네일, 하단 내비게이션 등
  features/
    today/                   오늘 화면, 운동 카드, 운동 선택 시트
    player/                  운동 플레이어 (YouTube IFrame API, 자동 다음 영상)
    completion/              운동 완료 화면 (근력 운동 Y/N)
    calendar/                월간 캘린더, 날짜 상세/기록 수정
    stats/                   통계, 차트
    routine/                 루틴 편집기
    settings/                설정
pwa/sw.js                    서비스 워커 템플릿 (빌드 시 dist/sw.js 생성)
public/                      manifest, 아이콘
```
